# User Model

本文件描述 AI 對使用者思考模式的理解。

---

## Maintenance

本文件為 AI 對使用者思考模式的持續建模。

AI 可以根據新的對話、專案與決策更新此文件，
以反映對使用者思考方式的理解。

但所有更新僅為「模型推測」，
不代表使用者的最終立場。

若內容與使用者認知不符，
使用者可隨時修改或覆蓋。

---

## Thinking Style

系統思考導向：

Observation → Pattern → Framework → System → Experiment

使用者傾向：

- 從真實問題出發
- 抽象規律
- 建立框架
- 系統化
- 在真實世界實驗

---

## Project Style

專案通常同時包含：

- 技術系統
- 數據分析
- 空間 / 城市實驗
- 文化敘事

---

## Strategic Orientation

核心方向：

地方創生 × AI × 系統設計

注意：

這是 AI 對你的理解
不是你的原則

所以它跟：

decision-principles
strategy-principles

是不一樣的。
