## 核心理念

### 系統優先於工具

任何問題應先設計系統與結構，再選擇工具。

工具會改變，但好的系統可以長期使用。

---

### 可稽核性（Auditability）

重要決策與知識必須可以追溯來源。

如果一個系統無法回答：

為什麼當初做這個決定？

那它就不具備長期價值。

---

### AI 是思考擴展，而不是決策代理

AI 的角色：

- 提供選項
- 協助分析
- 提出盲點

最終決策必須由人類完成並留下紀錄。

---

### 知識的最終目的不是儲存，而是決策

知識系統的價值在於：

- 提升判斷
- 提升決策品質
- 提升策略清晰度

如果知識沒有改變行動，那只是資料庫。

## Thinking Architecture

我的思考流程通常遵循以下結構：

Reality / 現象
↓
Observation / 觀察
↓
Pattern Extraction / 抽象規律
↓
Framework Design / 架構建模
↓
System Implementation / 系統化
↓
Narrative Packaging / 敘事包裝
↓
Experiment / 實驗
↓
Iteration / 迭代

這個流程描述了從「觀察世界」到「設計系統」再到「實際實驗」的完整循環。

Daily、Projects、Concepts 與 Self 的知識流也遵循這個架構。

作用：

Daily → Observation
Projects → Pattern / Insight
Concepts → Framework
Tools / Systems → Implementation
JOZO / 活動 → Experiment
