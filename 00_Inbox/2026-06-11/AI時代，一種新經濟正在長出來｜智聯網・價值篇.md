王強 騰訊研究院前沿科技研究中心主任

2026 年的夏天，中文互聯網圈出現了一個有趣的現象。日活（DAU）這把單一的尺子不那麼好用了。當 AI 助手替用戶去辦事，Agent根本不需要打開我們的 App，而是通過API、MCP、A2A、CLI等方式調用能力。APP打開次數變少了，是產品變差了，還是用戶的事更高效地辦成了？這把尺子已經分不清。

在矽谷，a16z 的年度報告裡直接寫了一句話：屏幕時代終結。或許未來我們可以給日活換成了一個新概念：任務完成率 TCR（Task Completion Rate）。它衡量的不是用戶打開你的產品幾次，而是用戶交給 Agent 的一件事，到底有沒有被完整地、可驗證地辦成。

在不遠的將來，整個互聯網行業可能要換一把衡量的標尺。這背後，其實是商業模式的代際更替。智聯網，這種以Agent為行為主體的新運行方式，正在悄然生長，有望成為移動互聯網的升級版。

**當前移動互聯網商業模式的全景**

移動互聯網過去十幾年，看似形態各異，但所有變現方式主要是幾種基礎形式。

廣告是最重要的商業模式，按曝光、點擊、轉化收錢。CPM（每千次曝光定價）、CPC（每次點擊定價）、CPA（每次行動轉化定價），三套刻度同時在用，把人的眼球時間精確到分秒。Alphabet 2025年全年廣告收入3427.21億美元，佔總營收的85%；Meta 廣告收入佔比 97% 以上。這是注意力經濟最直接的變現通道，也是整個移動互聯網的財務底色。

其次是訂閱，按時間收錢。從 QQ 音樂會員、愛奇藝視頻會員，到 Netflix，月費或年費換取去廣告、高品質、獨家內容。這是數字內容產品最穩定的收入方式。

再有是佣金，按交易額抽成。電商訂單GMV抽成、外賣訂單抽成、網約車單筆抽成、應用商店分發抽成，這是平台型生意最穩固的收入來源。

此外還有服務費等，是平台向生態參與方變現的方式。如，電商平台向商家收取店鋪裝修費、推廣費、保證金，SaaS 公司向企業收取功能模塊費，本質上都是把流量和工具切片打包賣給商家。

這些模式看似差異很大，其實有一個共同的底層假設：用戶的注意力是有限的（一天24小時為天花板），行為是可觀測的。無論是廣告、訂閱、佣金還是服務費，本質上都在圍繞一個樸素的問題做文章，即用戶在哪裡花時間、花了多少錢。

但这套體系在AI時代，有可能出現新的變化。當Agent替用戶去辦事，注意力不再停留在頁面上，這就會讓廣告失去了曝光基礎。當一個 Agent 同時調用十多家服務方的資源，完成一項複雜任務時，過去包年付費訂閱的方式可能不再適用，按次按量計價的需求會越來越多，小額高頻交易成為剛需。

**商業鏈路的變化正在醞釀**

也許有人會問一個樸素的問題：移動互聯網時代不也有按結果付費嗎？應用商店的 CPA、網約車的按單抽成，電商的 CPC、聽起來都跟按結果計費有關。智聯網時代真的有那麼不同嗎？

目前看，區別主要有三條，不在賣什麼，而在誰來做、誰記得、誰來付。

首先，執行者從人變成了機器。
移動互聯網時代，App 是工具，用戶自己是執行者，按按鈕、填表格、看廣告、做決定都是用戶親力親為。智聯網時代，Agent 才是執行者，用戶只下一個意圖，剩下的所有動作（搜索、比價、調用、決策、付款）都由 Agent 完成。這個區別決定了：所有圍繞人的注意力建立的計價方式，從根上失去了對象。Agent不需要被吸引、不會被廣告打動、也不會因為頁面好看多停留三秒。

其次，價值儲存器從賬號變成了上下文。
移動互聯網時代，賬號是核心資產，因為賬號裡有我們的購買歷史、社交關係、內容偏好等，換 App 甚至意味著在數字空間重建身份。智聯網時代，上下文（Context）成為核心資產。我們跟 Agent 說過的每一句話、辦過的每一件事、表達過的每一個偏好，都在沉澱。遷移成本不僅是丟失賬號，更是丟失記憶，而後者比前者深得多。

再次，付款決策開始讓渡給 Agent。
移動互聯網時代，用戶是付款主體。而智聯網時代出現了一個新現象，在部分場景下，付款決策開始讓渡給 Agent。比如 Agent 替我們比價、替我們下單、替我們訂機票、候補火車票等。當 Agent 替我們做決定時，各類服務的銷售對象就從“說服我們”變成了“要讓 Agent 選上”。這就是為什麼 GEO（Generative Engine Optimization，生成式引擎優化）開始逐步替代 SEO，優化對象從人的眼球變成了 Agent 的偏好。

可以看到，未來的智聯網時代，不是某一種商業模式在升級，而是整條價值鏈路在換基。

這些區別匯聚到一起，也指向一個更大的問題，入口之爭並沒有消失，只是換了戰場。移動互聯網時代，入口是 App 圖標，誰佔據了手機屏幕的第一屏，誰就拿走了用戶注意力的第一入口。智聯網時代，入口變成了誰第一個接住用戶的意圖。當用戶說出一句話，第一個理解這句話、並且有能力調度資源去執行它的 Agent，就是新時代的入口。這解釋了為什麼Apple Intelligence 嵌入 Siri、Google 把 Gemini 植入安卓，它們爭的不是一個新 App，而是新一代入口的卡位權。誰是用戶開口說第一句話的對象，誰就掌握了意圖分發的起點。從這個角度看，智聯網時代的入口之爭可能會比移動互聯網更激烈，因為它爭的不是有限的屏幕空間，而是無限的用戶意圖。

**商業模式的新探索**

互聯網商業模式歷史告訴我們一個樸素道理，即最後能跑通的模式，往往不是最先進的，而是最簡單的。CPM 、CPC、CPA等之所以戰勝了早期各種廣告效果衡量法，根本原因是它把廣告交易簡化到三方都不會爭。廣告主認這個數字、平台認這個數字、第三方監測也認這個數字。

我們看到，行業內，已經有多種新模式在探索，也都還在試錯。看哪種能率先把簡單清晰、可持續給跑通，哪種就最可能成為智聯網的新 CPM。

大模型剛出現時，很多應用都採取了訂閱服務的模式，每月20美元訂閱費幾乎成為行業標配。但是不同用戶的用量差別很大，由此還衍生出不少二道販子模式，即把一個訂閱賬戶再賣給好幾個人用。特別是今年龍蝦火爆後，純訂閱付費的用戶Token消耗量急劇上漲，導致Anthropic 4月5日起切斷了Claude Pro（20美元/月）和Claude Max（200美元/月）訂閱用戶通過OpenClaw等第三方框架的訪問權限，要求改回API接入，按量付費。

所以，當前Agent應用，幾乎都是訂閱加消耗的付費模式，如Manus、Genspark、Cursor、Lovable等。它保留了訂閱的預算可控感，又引入了消耗的彈性，這樣重度用戶多付費，輕度用戶也能安心用。

當前已經非常成熟，且未來有可能長期存在的，就是token按量調用的定價模式，這也是Token經濟的最基本商業模式。這套模式根據每百萬Token的輸入和輸入分別定價，如果命中緩存，價格會大幅下降。全球最貴的當屬Anthropic的Claude模型報價，以最新的Claude Opus 4.8為例，輸入5美元，輸出25美元/百萬token。同時，Token的消耗，跟分詞器也有很大關係，不同家的模式，以及不同代的模型，可能會採用不同的分詞器，而導致模型消耗價格大幅提升。如，Claude Opus 4.7 及後續版本採用了與之前模型不同的新分詞器，這有助於提升其在各類任務中的表現。但對於相同的固定文本，新分詞器可能多消耗高達 35%的 token。而相比Claude，國內的模型報價則便宜很多。由此，行業內也興起了多模型路由的模式，即80%的一般性任務，用國產開源大模型來做，追求更高的性價比，最難的20%的任务，交由Claude Opus 4.8、GPT 5.5來做，追求更高質量的完成度。

同時，一些新的模式探索也在進行中。最典型的是節約分成，代表玩家如，Salient（AI 催收按催回款分成）、Sierra（按解決工單數計費）。這是 Sierra 創始人 Brett Taylor 最引以為傲的商業模式創新，因為傳統的客服軟件是按坐席賣錢的。但这有一個悖論，即AI 越強，企業需要的客服人類就越少，那買的坐席就越少，軟件公司反而少賺錢。Sierra 徹底打破了這一矛盾，它採用結果導向型計費。企業不需要為 AI 佔了多少個坑位給錢，而是為每一次成功的服務買單。如果 AI 只是做了一個簡單的路由（把客戶轉接給人類），它不收或者只收極低的流量費；只有當 AI 獨立、完整地幫客戶解決了問題（比如成功辦理了退款、修改了訂單、挽留了退訂），它才會收取一筆解決費，通常在每單 1 到 1.5 美元左右，遠低於人類客服 10-15 美元的成本。

這種模式的邏輯很清晰，客戶多掙（少花）的，乙方分一杯羹，雙方利益完全對齊。這套模式中國並不陌生。電力領域的 EMC（合同能源管理）已經跑了三十年。節能服務公司前期出資改造客戶的設備，從客戶因此節約的電費裡分成（通常 50% 到 70%），合同期滿設備歸客戶。EMC 三十年總結出了三條經驗：基準線必須事先封存（避免事後扯皮），節約必須可第三方驗證（電表數據是公允裁判），合同期加階梯分成衰減（避免基準線漂移）。這三條對 AI 節約分成幾乎是現成的合同範式。其難點是基準線漂移，因為做一年之後，客戶會覺得反正現在效率高已經是常態了，憑什麼繼續給你分成？

還有一種可能的方式是專家數字分身調用付費。當前非常流行的Skill，可以看作是這種模式的雛形。當然，目前大量的Skill還是廣大開發者和用戶免費分享，上傳到ClawHub 、SkillHub等社區。而未來，一些高質量的Skill完全有機會商業化轉化。還有一種未來很具前景的是專家數字分身付費訂閱，或者按次付費模式。暢想一下：當前Workbuddy上的專家平台上，已經匯聚了不少專家團和個人專家，用戶可以一鍵召喚專家答疑和做方案。一些頭部專家已經被調用數百萬次，如果未來這些調用商業化，將是一個巨大的長尾市場。就像互聯網讓標準化的商品和服務實現了供需對接，專家經驗也將藉由智聯網第一次有機會成為標準化的產品，獲得市場認可和變現。

這有可能是智聯網的雛形，它不是更聰明的 App，也不是更好用的搜索，而是一個讓人類專業經驗第一次可以脫離時間和物理限制，最大化複用的市場。

還有一種未來的可能模式，則是適應多Agent協作，以及多渠道資源獲取的新模式。這種模式當前還沒有明確的標的，但需求已經在顯現。假設我們要做一份具身智能公司的市場研究報告，需要調用證券交易類型的MCP，工商註冊登記的API 、投融資類服務的API、行業研究報告和諮詢公司的MCP，前沿技術論文庫的MCP、以及一些專業資料庫的API等等，這些廣泛的數據來源，如果是按照現有的訂閱式，訂閱如此多的信息源，顯然對用戶是一個很高的成本，如果能按次調用，按量計費，則可以滿足更廣大非專業用戶的日常使用需求。原來之所以沒法實現，是因為人從這些海量信息源查找、整合信息的難度太大，而有了Agent，可以非常方便地查詢和處理，因而也需要配合相應的定價和協作模式創新。

**按結果付費還需明確標準**
**搭建Agent支付基礎設施**

按結果付費要落地，必須要明確任務和驗收標準，避免容易發生的扯皮，需跨過四道門檻：說不清、算不清、守不住和認不准。過去一些傳統的實踐，為我們解決智聯網時代的爭議，已經奠定了一些解決思路，可供我們參考。

除了上面的四道門檻，針對Agent交易小額高頻的特徵，還需要一種全新的金融服務，即Agent 支付，小額高頻的新結算基礎設施。Stripe 已經在 2026 年初推出了 Agent Payment API，允許 Agent 在預授權額度內完成支付。

今天人類的支付體系，大多是低頻大額或中頻中額，如月付 20 美元訂閱、單筆 50 元外賣、年繳數百元會員等。但 Agent 支付的特徵恰好相反：小額高頻，一次調用幾分錢、幾毛錢應該都是常態。一個任務串下來，如果調用幾十個服務方資源，每一次調用都要走人類支付的確認流程，整件事根本跑不起來。這意味著 Agent 支付必須具備一些新特徵。

第一，極低單價可結算。服務的定價可以低到一分錢甚至更低。因為 Agent 調用是高頻的，薄利可以靠量來堆。這讓過去因為交易成本太高而無法定價的微服務，第一次有了商業化的可能。

第二，免確認自動扣款。Agent 在預算授權範圍內自主完成支付決策，不需要每筆都彈窗讓用戶點確認。這要求一套新的授權機制，即用戶設上限，Agent 在上限內自由調度。

第三，跨服務即時清算。一個任務可能串聯十幾個服務商，Agent 完成任務後系統自動拆賬、即時清算，不需要人工對賬。

更深一層看，Agent 支付會催生全新的定價邏輯。當單次調用成本趨近於零，服務商就不再需要把定價抬高來覆蓋交易摩擦。一個翻譯服務甚至可以按句收費，一個法律條款檢索可以按條收費，一個數據清洗工具可以按行收費。過去因為定價粒度太粗而被迫打包的服務，現在可以被拆成原子級別單獨售賣，這或許正是智聯網經濟得以運轉的微循環系統。

**一種新經濟正在長出來**

a16z 判斷未來軟件公司大致會分成三類。一是正在歸零的，即按席位收費的工具型 SaaS，會受到新模式的嚴重挑戰。二是正在被削弱的，是大型企業軟件，原來企業軟件一旦進入核心業務流程，替換成本、遷移風險和組織阻力都很高。客戶即使不滿意，也很難更換系統。但Agent模式正在逐步改變這種綁定。三是正在湧現的，即直接賣結果的 Agent 原生模式。前兩類是存量博弈，第三類切的是數十萬億美元的勞動力預算，這是未來智聯網巨大的增量空間。

類似的判斷不只來自 a16z。Bessemer Venture Partners 在 2026 年的雲指數報告中指出，頭部 AI 原生公司的收入增速已經是傳統 SaaS 公司的三倍，但真正拉開差距的不是增速本身，而是淨收入留存率。按結果付費的 AI 公司，客戶擴展消費的意願遠高於按賬號付費的傳統SaaS。McKinsey 的一項研究也佐證了這個趨勢：企業在 AI 工具上的支出，正在從 IT 預算轉向業務預算，換句話說，軟件不再吃 IT 預算，而是吃勞動力預算，這才是數十萬億美元增量空間的真正來源。

但所有這些新商業模式都建立在一個底層條件之上，即Token 效能（Token Efficiency）的大幅提升。它衡量的是每一塊錢買到多少有用的智能，既包括效率（同樣任務消耗多少 Token），也包括質量（這些 Token 轉化成多少正確結果）。Token 效能將成為效果經濟時代的全要素生產率。

最後，還有一個根本的問題需要關注，就是智聯網真正的原生應用會長什麼樣？AI Native 的出現規律，大概率也會遵循歷次技術變革之路：先改造，後湧現。

PC 互聯網剛出現時，第一批產品是把報紙搬上網（雅虎新聞）、把百科全書搬上網（維基百科）。但真正定義那個時代的原生物種，是搜索、社交和電商。當大量內容湧上網絡，就必然產生發現和篩選的需求。再往後，當大量用戶湧上網絡，就必然產生連接彼此的需求，於是社交網絡出現了。當大量商品湧上網絡，就必然產生交易撮合的需求，於是電商出現了。

移動互聯網也循此路徑。第一批產品是把 PC 搜索做成移動搜索，把 PC 購物做成移動電商。但真正顛覆的原生物種，來自一個結構性變化：人不再主動找信息，而是信息主動找人。推薦算法和信息流成了移動時代最流行的產品形態。直播電商也類似，手機讓商品展示有了講故事、去現場、實時互動的新可能，於是直播電商跑出來了。

現在 AI 來了，我們正處在第一階段，把 AI 嵌入現有產品。搜索加了 AI 摘要，客服系統加了機器人，Office 加了智能助手。這一波改造當然有價值，但它不是終局。終局是什麼？如果規律仍然成立，我們應該問：當大量 Agent 湧入網絡之後，會呈現怎樣的模式？

加上前面提到的Agent支付，未來可能是三大方向，即用戶主 Agent 、Agent 任務市場和Agent 支付基礎設施。它們不是獨立存在的，而是互相咬合的。主 Agent 讓用戶可以省心，任務市場讓供需可以匹配，支付讓交易可以發生。三者合在一起，才是一個完整的 Agent 經濟系統的雛形。

用戶主 Agent是個人意圖的統一入口。這個主 Agent 承接用戶的各類需求，不管是訂機票、寫報告、管理日程、投資理財還是預約體檢。它了解你的全部上下文，知道你的偏好、預算、時間約束、風險偏好。甚至他可以經受授權，一定程度上代表你，去和各個垂直領域的服務型 Agent 對接和決策。這個架構一旦成立，商業模式的重心就會發生根本性遷移：從 to C變成 to Agent。服務的客戶不再是人，而是人的Agent。各類服務可能需要去考慮，如何佔領Agent的心智，即在主 Agent 的評估體系裡得分最高。

Agent 的任務市場會催生競價與評測平台。當用戶有一個任務要完成，而市場上有成百上千個服務型 Agent 都聲稱能做這件事，就必然需要一個撮合機制。想像一個場景：你讓你的主 Agent 幫你做一份競品分析報告。主 Agent 把這個任務發布到一個開放市場上。三十秒內，十幾個專業調研 Agent 報價，有的按完成度收費，有的按頁數收費，有的按數據源數量收費。市場平台根據歷史評分、完成率、用戶評價等做排序，你的主 Agent 綜合價格和質量做出選擇。這就是 Agent 時代的競價平台。它和今天搜索引擎廣告的競價排名有本質區別。競價排名賣的是展示位置，Agent 競價平台賣的是任務完成承諾。但這個平台要跑通，至少需要解決三個問題：一是如何評測任務完成質量？是客戶主觀評分、第三方審計、還是預設的量化基準？二是如何防止惡意低價中標？有的 Agent 可能報極低價拿到任務，再用低質量交付來騙取首付款。三是如何建立 Agent 的信用體系，類似信用分，但對象是 Agent 而非人。

所以，智聯網的效果變現能否真正成立，還取決於一件更基礎的事，在一個 Agent 滿天飛、人類逐漸隱入對話框背後的世界裡，我們怎麼知道一個 Agent 是誰、它做過什麼、它說的是不是真的？換句話說，當機器開始替人辦事，互聯網的信任機制必須重寫，這將是下一篇要討論的問題：信任篇・可證明的 Agent。
