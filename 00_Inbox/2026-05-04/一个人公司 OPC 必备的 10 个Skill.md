陈宇明 *2026年4月5日 13:05*

这些Skill的作者是 Sahil Lavingia，他在2021年写过一本书《The Minimalist Entrepreneur: How Great Founders Do More with Less》。

这本书在豆瓣高达7.8分。

萨希尔·拉文吉亚（Sahil Lavingia）是 Gumroad 的创始人兼 CEO，也做天使投资，业余画画。

他的经历有点不寻常。

15 岁开始创业，大一就加入了 Pinterest，是联合创始人之一，公司二号员工。后来放弃了手上的期权，出来自己干。

2012 年创立 Gumroad。 然后事情开始走下坡路。

2015 年，增长没达到预期，他裁掉了四分之三的员工，只留下 5 个人。

到 2016 年，就剩他一个人了。 就是在那个时候，他开始想清楚一些事。公司不一定要做大，不一定要烧钱扩张。

他的结论很简单：先活下去，活下去靠的是盈利，不是融资。

他把这套想法整理成一套经营逻辑——找到你热爱的、市场需要的、你擅长的、能赚钱的交叉点，然后专注在那里。

Gumroad 后来确实缓过来了，增长也回来了，投资人重新开始感兴趣。

但萨希尔这时候反而不想做独角兽了。

他更在意的是公司能不能持续增长，而不是估值能不能冲到十亿。

他把这本书里面的内容提炼出来了 10 个Skill。

https://github.com/slavingia/skills

先找到你的目标用户，搞清楚他们真正头疼的是什么，然后动手。

不用等产品做好。

先手动跑，能交付就交付，边做边改。

代码的事之后再说。

客户也是一个一个谈来的，前 100 个没有捷径。

定价从第一天就要想清楚，别等"做大了再收钱"，那一天往往不会来。

站稳之后靠内容慢慢积累受众，花钱和招人都要量力而行，别为了增长把利润烧光。

团队文化也是，建一个自己愿意待的地方，不然做大了也没意思。

每次要做决策，拿极简原则过一遍，问问自己：这件事真的必要吗？

如何使用？

安装方式：

在 Claude Code 里运行：

```bash
/plugin marketplace add slavingia/skills /plugin install minimalist-entrepreneur
```

只需两步 Claude Code 会自动拉取仓库并注册全部 10 个技能。

技能列表：

| 技能 | 指令 | 使用场景 |
| --- | --- | --- |
| **寻找社群** | `/find-community` | 想找创业方向、定位目标人群 |
| **验证想法** | `/validate-idea` | 测试一个商业点子值不值得做 |
| **最小可行产品** | `/mvp` | 准备做第一款产品，不知道该做哪些功能 |
| **流程化** | `/processize` | 有产品思路，想先手动跑通服务再写代码 |
| **首批客户** | `/first-customers` | 产品做好了，想搞定前 100 个用户 |
| **定价** | `/pricing` | 制定价格、考虑调价时用 |
| **营销计划** | `/marketing-plan` | 产品市场匹配度不错，想靠内容放大规模 |
| **稳健增长** | `/grow-sustainably` | 做支出、招人、扩张相关决策时 |
| **公司价值观** | `/company-values` | 梳理企业文化、准备招人时 |
| **极简复盘** | `/minimalist-review` | 快速判断任何商业决策是否合理 |

如果你想把这些技能使用的更好。

建议把《小而美》读一遍。

技能本身只是操作层面的东西。

你照着指令跑，能用，但不一定用得对。

读懂背后的极简创业逻辑，理解每一个技能设计的初衷。

比如为什么要先找社群再验证想法、为什么强调手动落地再产品化，才能真正吃透这些工具的精髓，把技能用出效果，而不是机械套用。

才能真正把极简创业的思路融入到每一个决策和行动里，发挥这些技能的最大价值。
