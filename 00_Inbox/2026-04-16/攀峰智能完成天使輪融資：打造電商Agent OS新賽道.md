攀峰智能（K2 Lab）完成數千萬元天使輪融資，由華控資本領投、云時資本跟投，資金用於模型研發、團隊增長及市場擴張。

**創始團隊**
三位聯合創始人均來自阿里釘釘。CEO 王銘曾任釘釘最年輕副總裁；CSO 汤明磊深耕產業數字化投資研究十年；CTO 趙先烈曾任釘釘AI PaaS負責人。

**核心產品：Moras 平台**
TikTok 達人全流程 Agent OS，服務粉絲5千~5萬的達人群體：
- 功能：選品推薦 → 腳本生成 → 智能剪輯 → 視頻發布 → 數據分析
- 活躍達人月均 GMV 接近1萬美元，部分突破10萬美元
- 首周出單率達70%以上

**商業模式創新**
探索兩種模式：
1. 人類雇用 AI（平台抽成50%）
2. AI 雇用人類（用戶低比例分成）

測試結果：用戶傾向選擇後者（AI雇用人類）。

**核心理念**
CEO王銘提出「人類不想 in the loop」——AI 應補齊人類短板、讓人徹底脫手。技術架構採用 Multi-Agent，受 Claude Code 和 OpenClaw 啟發，建立 A2A 原生電商操作系統。
