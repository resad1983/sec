# 千問向第三方 Agent 全面開放

千問平台正式向所有企業開放品牌 Agent 運營權限。企業可在千問 APP 中自訂 Agent 人設、服務能力與邊界，並透過對話形式向用戶提供各類產品和服務。用戶透過自然語言表達需求，無需切換應用程式。

## 首批合作夥伴

瑞幸咖啡、肯德基、蜜雪冰城、東方航空等高頻消費與生活服務企業率先接入測試。

## 應用場景示例

- 瑞幸咖啡 Agent 可「主動提醒用戶中午排隊時間長，建議提前半小時點單」
- 東方航空 Agent 可「智能推薦行程方案，並一站式解決出行服務」

## 策略意義

這標誌著 AI 應用競爭正從「功能比拼」轉向「生態服務能力比拼」。千問有望成為用戶連結品牌服務的新入口——類似微信公眾號在 2013 年扮演的角色，但這次的介面是自然語言對話，而非圖文推送。

品牌首次能在 AI 平台構建具有人格化服務的品牌智能體，讓每個企業擁有理解用戶偏好、主動提供服務的數位化分身。

## 對顧問工作的啟發

企業在 AI 平台的「Agent 佈局」即將成為品牌基礎設施的一部分。協助客戶思考「如何設計品牌 Agent 的人設與服務邊界」，是新興的顧問切入點。
