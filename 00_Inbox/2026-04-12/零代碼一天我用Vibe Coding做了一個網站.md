作者 Hanni 記錄了透過「Vibe Coding」（氛圍編程）方式，在半天內零代碼完成網站上線的全過程。

**戰略規劃階段**

作者首先釐清四個關鍵問題：目標受眾（科技創業者、產品經理）、用戶需求、核心價值主張與差異化定位。

**技術實現流程**

1. 向 Claude 提供網站需求規格（名稱、定位、色調、字體等），AI 生成 HTML 代碼
2. 透過截圖反饋迭代修改，共改動約 20 次
3. 購買域名 gtmstar.com（150 元以下）
4. 利用 GitHub + Vercel 進行代碼託管與部署
5. 配置 DNS 解析完成上線
6. 設定 sitemap.xml 與 robots.txt 進行 SEO/GEO 優化

**運營策略**

幾個實用工具組合：
- 使用 Notion 作為內容庫
- Substack 或微信公眾號發布 Blog
- Tally 表單進行客戶篩選

**核心概念：GEO（生成式引擎優化）**

作者提出「生成式引擎優化」（GEO）概念，探討在大模型時代，如何讓 AI 準確理解並推薦你的身份與內容——相較傳統 SEO 的進化。

**重要提醒**

該方案適合海外託管驗證，國內商業運營需完成備案手續。
