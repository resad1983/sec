The Set 是一家倫敦獨立豪華飯店品牌聯盟，正以「非積點型忠誠計劃」對抗大型連鎖的同質化趨勢，主張情感連結比交易型獎勵更能建立真正的品牌忠誠。

## 計劃概況

- 透過 Global Hotel Alliance (GHA) 運作，旗下涵蓋逾 950 家飯店、50 個品牌、100 個國家
- 會員數超過 3,400 萬
- 使用「Discovery Dollars」（可從直接預訂、旅行顧問或 GDS 通路累積，不含 OTA）

## 核心哲學

執行長 Robin Stangroom 強調：豪華旅客追求的是「安全感」（對服務品質的保障）加上「個人化、真實的體驗」，而非積點換免房。

情感連結 > 交易性獎勵 → 這是 The Set 對抗積點同質化的核心主張。

## 差異化策略

- **非競爭模式**：每個目的地原則上只代理一家飯店，保持各館獨立性
- **抵制「米色化」**（beigification）：獨特性是商業策略，不只是美學選擇
- **代表成員**：香港 The Upper House、曼谷 The Siam、柬埔寨 Shinta Mani Wild

## 2021 年轉型

The Set 在 2021 年從「擁有三家飯店（倫敦、巴黎、阿姆斯特丹）的飯店集團」轉型為「純品牌聯盟」，這是一次商業模式的根本重塑——從資產重型到輕資產的策展型品牌。
