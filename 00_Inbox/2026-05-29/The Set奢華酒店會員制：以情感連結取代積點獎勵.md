一個總部位於倫敦的獨立奢華酒店品牌聯盟，正在將自己定位為高端住宿市場日益同質化趨勢的對立面，並主張情感連結與獨特體驗正在變得比傳統積點型忠誠計畫更為重要。

The Set 執行長 Robin Stangroom 向 TTG Asia 表示，該公司的忠誠策略圍繞個人連結而非交易性獎勵建立。該公司於2021年從最初擁有倫敦、巴黎、阿姆斯特丹三家自有物業，轉型為純品牌聯盟模式。

The Set 的賓客計畫「The Set Discovery」與全球酒店聯盟（GHA）合作運營，讓會員能夠跨越100個國家、50個品牌、超過950家酒店使用，會員數超過3400萬。無論是直接預訂、透過旅遊顧問或 GDS 管道預訂，會員均可累積 Discovery Dollars，但透過線上旅遊平台（OTA）的預訂除外。

「這不會疏遠旅遊顧問，而他們是我們生態圈中至關重要的一部分，」Stangroom 說。

The Set 透過「非競爭性選品」策略進行差異化——通常每個目的地只選擇一家成員酒店。Stangroom 表示，這讓獨立酒店能夠提供清晰的奢華定位，同時保留各自的個性。

「奢華旅行者想要那種安全感，知道自己能獲得頂級服務，」他解釋道。「但他們也想要更個性化、更真實的體驗。而我們兩者兼顧。」

目前成員包括香港 The Upper House、曼谷 The Siam，以及柬埔寨 Shinta Mani Wild——這是一個由建築師 Bill Bensley 設計的15頂帳篷度假村，賓客乘坐橫越叢林樹冠的飛索纜車抵達。

Stangroom 認為，奢華住宿面臨的最大風險之一是他所描述的「米色化」（beigification）——隨著品牌越來越謹慎，酒店設計和體驗的同質化日益加劇。他補充說，對於獨立酒店而言，獨特性不是創意冒險，而是商業策略。

「旅行的意義在於拓寬視野、展現不同觀點。如果一切看起來都一樣，這是不可能實現的。」

對於向高端客戶銷售產品的旅遊顧問來說，The Set 將自己定位為既尋求一致品質、又不願犧牲個性的旅行者的選擇方案。
