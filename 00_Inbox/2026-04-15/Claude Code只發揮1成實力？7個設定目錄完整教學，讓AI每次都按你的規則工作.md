如果你有在使用Claude Code來開發程式或工具，如果你從來沒了解過.claude資料夾，那你只用了Claude Code 10%的能力而已。

透過一個結構化的`.claude/`資料夾，讓你把規則、習慣、工作流程「記錄下來」，讓Claude每次都能精準按照你的方式工作。

**7個設定目錄介紹：**

**1. agents - 你的AI專屬團隊**
自訂的AI助理，每一個都有自己的角色設定、可用的工具和行為規則。當Claude遇到符合的任務，會自動把工作交給對應的Agent，像一個主管把任務分配給不同的組員。

**2. CLAUDE.md - 全域規則說明書**
記錄你的偏好設定、工作規範、注意事項。Claude每次啟動都會讀取，相當於給AI的「上工前必讀」。

**3. commands - 自訂指令集**
建立你自己的/指令（slash commands），把常用的複雜操作包裝成一個簡短的指令。

**4. hooks - 自動化觸發器**
在特定事件發生時（如每次存檔、提交程式碼前），自動執行指定動作。

**5. memories - 長期記憶存放區**
讓Claude記住重要資訊，如專案背景、個人偏好、常見問題的解法。

**6. mcp.json - MCP伺服器連線設定**
設定MCP（Model Context Protocol）伺服器的連線資訊，讓Claude能存取外部工具與服務。

**7. settings.json - 核心行為設定檔**
控制Claude Code的核心行為，如自動批准的工具、語言偏好等。

善用這7個目錄，讓Claude真正成為了解你工作方式的專屬AI助理。
