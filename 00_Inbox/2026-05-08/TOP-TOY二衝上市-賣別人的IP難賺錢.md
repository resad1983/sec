成立不到八年，由名創優品創始人葉國富一手主導的潮玩品牌TOP TOY ，如今已是行業老二。 2025 年營收 35.87 億元，市佔率 4.8% ，僅次於泡泡瑪特。然而，它的毛利率卻只有 32% ，還不到泡泡瑪特的一半。

為什麼賣得不少，賺得卻不多？招股書寫得很清楚：僅 2024 年， TOP TOY 的授權費就高達 3278 萬元，擠佔了大量毛利空間。扣掉這筆剛性成本，再減去渠道和供應鏈的開銷，自己留下的就所剩無幾了。

2025 年營收漲了近九成，淨利潤卻從 2.94 億掉到 1.01 億，淨利率從 15% 跌到不足 3% 。賣得越多，賺得越少，問題就出在 “ 別人的 IP” 上。

半年內第二次向港交所遞表， TOP TOY 換了投行、明確了 IP 戰略、拿到了新融資，籌碼確實更足了。但第一次闖關失敗的核心問題還沒解決，而對賭協議還在倒計時 ——TOP TOY 若 2 年內無法上市，將觸發 5.74 億元優先股回購義務。

這一次，它能敲開港交所的門嗎？

### 三年狂奔，沒賺到錢？

從財報來看， TOP TOY 近幾年的增長曲線確實亮眼。2023 年到 2025 年，其營收從 14.61 億元漲至 35.87 億元，複合增長率 56.7% 。

其中， 2025 年單年增長 87.9% ，比前一年多賣了 16.8 億元。按 GMV 計算，它的市佔率為 4.8% ，排在行業第二，僅次於泡泡瑪特。

不止國內增長迅猛，它的全球化佈局也開始真正跑通。馬來西亞、印尼、泰國、日本等市場陸續開出線下門店， 2025 年其海外收入達到 2.96 億元，佔總營收的 8.3% 。

按照招股書的規劃， TOP TOY 目標在五年內將海外收入佔比提升至 50% ，並建成全球 1000 家門店。泡泡瑪特尚未完全兌現的全球敘事， TOP TOY 想搶先講出來。

在產品層面，其品類結構也在持續優化，不再局限於單一盲盒賽道。搪膠毛絨從幾乎為零，到 2025 年佔比升至 31.6% ，證明它不只會賣盲盒。目前，它擁有 9800 多個 SKU ，涵蓋手辦、盲盒、毛絨、拼裝等多個品類。

渠道與供應鏈，則構成了它難以被模仿的底層優勢。 TOP TOY 依托名創優品的合伙人模式進行擴張，同時共享後者的全球供應鏈體系，並積累了 1200 萬會員。這些資源為它的運營提供了支撐。

不過，第一次遞表失效本身就說明：資本市場看到的遠不止這些增長數字。

真正讓投資人猶豫的是另一個問題：營收漲了那麼多，錢呢？

2025 年， TOP TOY 營收大漲 87.9% ，但經營利潤僅從 3.96 億元微增至 4.43 億元，增速 11.9% 。年度利潤更是從 2.94 億元掉到 1.01 億元，淨利率從 15.4% 跌至 2.8% 。增長沒有轉化成利潤 —— 錢被誰賺走了？

答案藏在 IP 結構裡。

2025 年， TOP TOY 的自有 IP 收入只佔 5.7% ，授權 IP 佔 51% ，他牌 IP 佔 43.3% 。

頭部自有 IP“ 糯米兒 ” 年銷 2 億元、 “YOYO” 年銷 1 億元，但對比泡泡瑪特，差距明顯 ——Labubu 一個 IP 年銷超過 141 億元。

這意味著什麼？ TOP TOY 賣的大多是別人的 IP 。動輒上千萬的授權費是一項剛性成本，導致毛利率被壓在 32% 左右，三年沒有明顯提升；而泡泡瑪特的毛利率為 72% 。增量營收的大頭，實際上被授權費吃掉了。

和泡泡瑪特的差距，不僅是量級的，更是模式的。 TOP TOY 的營收約為泡泡瑪特的 1/10 ，經調整利潤約為 1/25 ，自有 IP 佔比 5.7% 對 90% ，市值約為 1/24 。

泡泡瑪特是 IP 平台，靠 IP 賺錢； TOP TOY 更像是零售集合店，靠賣別人的 IP 賺差價。前者有定價權，後者則要看版權方的臉色。

此外， TOP TOY 的獨立性也受到質疑。招股書顯示，名創優品貢獻了其 45.5% 的收入，公司從決策到渠道都深度綁定。資本市場第一次問的問題是：這是一家獨立公司，還是名創優品的 “ 附屬品 ” ？如果是後者，估值就應該對標名創，而不是泡泡瑪特。

這些硬傷加在一起，解釋了為什麼第一次闖關失敗 —— 增長故事雖然動聽，但錢沒真正賺到， IP 也不是自己的。

### 半年變局，背水再闖關

第一次遞表失效後的半年裡， TOP TOY 做了幾件事。

首先，它更換了投行陣容，從中信證券換成了摩根大通與瑞銀。這意味著後續 IPO 將由國際投行負責承銷，可以接觸到更廣泛的國際投資者。

同時，其 IP 戰略在招股書中有更明確的表述：公司計劃持續加大自有 IP 孵化力度，逐步提升自有 IP 收入佔比。目前這一比例是 5.7% ，距離成熟潮玩企業仍有較大差距，但至少有了一個量化的方向。

業績方面， 2025 年全年營收已正式出爐， TOP TOY 實現了 87.9% 的高增長。

就在 TOP TOY 調整自身的同時，過去兩年的市場環境也在發生變化。

泡泡瑪特 2025 年財報發佈後，股價兩日跌幅超過 30% ，較歷史高點市值已近乎腰斬。雖然 2025 年其營收增速高達 184.7% ，但公司給出的 2026 年增速指引僅為 “ 不低於 20%” ，與市場預期形成較大落差。另一個引起投資者擔憂的信號是：泡泡瑪特核心 IP LABUBU 的收入佔比從 23.3% 升至 38.1% ，對單一 IP 的依賴度在加深。

市場由此意識到兩件事：第一，潮玩賽道的高增長神話正在降溫；第二，即使是行業龍頭，也難以擺脫對單一 IP 的依賴。

這對 TOP TOY 的直接影響是，整個行業的估值錨點被拉低了。市場不再單純為 “ 高增長 ” 概念支付溢價，而是開始追問盈利質量和 IP 的可持續性。 TOP TOY 的估值空間也因此被壓縮。

不論行業格局如何變化，擺在 TOP TOY 面前的路已經沒有太多選擇餘地。

2025 年 7 月的融資附帶了對賭條款：如果公司在 2028 年 7 月之前未能上市，就需要按 “ 發行價加 10% 年單利利息 ” 回購優先股，合計金額超過 5.74 億元。同時，公司的淨流動負債已從 2.16 億元增至 2.79 億元，短期償債壓力不小。

這意味著 IPO 從 “ 可選項 ” 變成了 “ 必選項 ” 。不是想不想上市的問題，而是必須上市。增長故事需要用來換取時間窗口，而這個窗口只剩下兩年。

即便成功登陸資本市場，對 TOP TOY 來說也不是終點，而是一場更持久的追趕。

### 兩年窗口，行業不等人

潮玩行業的洗牌期已然到來，留給 TOP TOY 的調整時間，只有兩年對賭期限。

2023 年之前，行業動輒 30% 以上的高速增長，到 2025 年已經回落到 21% 。賽道還在漲，但爆發期結束了，增量空間在收窄。

IP 的重要性會進一步凸顯。市場已經證明，它不再為 “ 開店速度 ” 和 “ 營收增長 ” 支付溢價，而是看 “IP 護城河 ” 和真正的 “ 盈利質量 ” 。

除了 IP ，海外市場的爭奪同樣關鍵。

依托名創優品的合伙人模式與全球供應鏈， TOP TOY 在渠道和供應鏈上有一定基礎。出海方面，名創在海外已佈局超 3500 家門店，這些渠道可以為 TOP TOY 所用，這是泡泡瑪特不具備的條件。

但之前提到的那些短板 —— 自有 IP 弱、增收不增利、過度依賴名創 —— 如果 TOP TOY 不能在兩年的窗口期內有所改觀，光靠渠道和供應鏈，很難撐起一個獨立的 IP 平台故事。

兩年時間轉瞬即逝，行業不會停下等待。

### 結語

泡泡瑪特的調整釋放了一個清晰的信號：潮玩賽道的下半場，不再是比誰跑得快，而是比誰的 IP 護城河深、盈利質量穩。

TOP TOY 的籌碼比第一次足。營收 87.9% 的增長、出海起跑的落地、國際投行的站台，這些都是實打實的加分項。

但命門還在。自有 IP 只有 5.7% ，毛利率只有泡泡瑪特的一半，近一半收入來自名創。對賭壓力鎖死了時間窗口，龍頭 “ 剎車 ” 重設了遊戲規則。

IPO 或許能敲開港交所的門，但也僅僅是敲開了門。從 “ 名創的附屬品 ” 到 “ 獨立的 IP 平台 ” ，這場跨越才是決定 TOP TOY 能否縮小與泡泡瑪特差距的關鍵一戰。
