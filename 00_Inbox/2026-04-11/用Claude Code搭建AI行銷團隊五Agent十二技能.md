許多行銷工作者面臨的痛點：時間不足、專業人力成本高、多工具協作效率低。通過AI Agent團隊化，可以讓一個人「變成一支軍隊」。

## 四步構建方法

1. **映射行銷職能** - 列出日常重複任務
2. **轉化為技能** - 將工作流標準化為可複用技能
3. **分組為Agent** - 按角色打包相似技能
4. **連接協作機制** - 設置自動分配和協調規則

## 實戰配置

**環境搭建包括：**
- VS Code 中安裝 Claude Code 擴展
- 創建品牌文件夾結構（含 context、templates、產出文件夾）
- 初始化 CLAUDE.md 項目憲法文件

**12 項核心技能覆蓋：**
- 內容創作（博客、文案、Lead Magnet）
- 視覺設計（PPT、社交創意、海報）
- 數據分析（報告、儀表板）
- 市場研究等

## 5 個專用 Agent 角色

數據分析師、內容創作者、市場研究員等各司其職，通過路由規則自動分配任務。

## 進階功能

支持 Notion 看板集成和移動端遠程控制，實現「真人決策 + AI 執行」的混合協作模式。
