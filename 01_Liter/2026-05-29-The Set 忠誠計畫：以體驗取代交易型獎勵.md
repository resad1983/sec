## 核心洞察

> 豪華飯店的忠誠計劃不應該是「積點換房」，而是「每次住宿都是獨一無二的情感事件」——The Set 的策略告訴我們：當市場同質化加速，「獨特性」本身就是商業競爭力，不只是美學選擇。

## 重點摘要

| 傳統積點型忠誠計劃 | The Set 非交易型忠誠計劃 |
|------------------|------------------------|
| 積點、等級、免費房 | 情感連結、個人化體驗 |
| 標準化服務保證 | 個性化、真實體驗 |
| 鼓勵高頻消費 | 建立深度品牌忠誠 |
| 同質化競爭 | 差異化定位（反「米色化」）|

- 2021 年從「資產重型飯店集團」轉型為「輕資產品牌聯盟」：去掉三家自有飯店，改為策展型代理
- 非競爭模式：每個目的地僅代理一家，保持各館獨立個性
- 透過 GHA 觸及 3,400 萬會員，覆蓋 950 家飯店

## 值得深思的問題

1. **對顧問工作的啟發**：勤美誠品的會員經營，如何從「交易型積點」升級為「情感事件型體驗」？有哪些具體的設計切入點？
2. **對地方創生的應用**：台中舊城的場域型商業，能否建立類似「The Set」的「非競爭性策展網絡」，讓各空間保有個性又共享流量？
3. **對系統設計的洞察**：「獨特性即商業策略」這個論點如何被量化？用什麼指標說服商業夥伴投入差異化而非跟隨同質化趨勢？
