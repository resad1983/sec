## 核心洞察

千問開放第三方 Agent 入駐，讓每個品牌能以「人設化服務智能體」進駐消費者日常——這是繼微信公眾號後最大的品牌觸點重塑機會，競爭的核心將從「功能」轉向「生態位置」。

## 重點摘要

| 面向 | 內容 |
|------|------|
| 核心開放 | 企業可自訂 Agent 人設、服務能力與邊界 |
| 首批入駐 | 瑞幸咖啡、肯德基、蜜雪冰城、東方航空 |
| 互動方式 | 自然語言，用戶無需切換 APP |
| 主動服務例子 | 「中午排隊長，建議提前半小時點單」 |
| 戰略定位 | 品牌服務的 AI 平臺入口，類比微信公眾號 |

## 值得深思的問題

1. **對顧問工作**：協助客戶設計「品牌 Agent 人設」將成為新興顧問服務——服務邊界怎麼設？語氣怎麼定義？主動服務的觸發條件？
2. **對地方創生**：臺灣缺乏類似千問的在地 AI 入口，但 LINE 或 Google Assistant 生態位是否有類比機會？
3. **對系統設計**：AI 平臺作為品牌入口，誰掌握「對話資料」？品牌智能體的數據主權問題值得關注。
