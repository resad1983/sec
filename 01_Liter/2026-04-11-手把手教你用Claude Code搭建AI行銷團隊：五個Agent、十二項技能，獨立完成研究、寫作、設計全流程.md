## 核心洞察

> AI行銷團隊不是「用AI幫忙寫文章」，而是把整個行銷職能系統化成可複用的技能庫 + 角色分工，讓一個人能調度多個專業代理協作。

## 重點摘要

- **四步建隊**：映射職能 → 技能化 → 分組為Agent → 設協調規則
- **12項核心技能**：涵蓋內容創作、視覺設計、數據分析、市場研究
- **5個Agent角色**：數據分析師 / 內容創作者 / 市場研究員 / 視覺設計師 / 策略師（各司其職）
- **CLAUDE.md作為憲法**：定義品牌聲音、目標受眾、禁忌詞，讓所有Agent有統一的「公司觀」
- **進階整合**：Notion看板 + 移動端遠程控制 → 實現「真人決策 + AI執行」

## 值得深思的問題

1. **顧問工作角度**：我現在幫客戶做的哪些行銷任務可以立刻被這套架構接管？能否先為自己的個人顧問品牌建一套？
2. **地方創生角度**：典典文創 / 不二製餅這樣的在地品牌，能否用這套低成本AI團隊解決人手不足的問題？
3. **系統設計角度**：技能庫（Skill Library）和CLAUDE.md的設計方式，本質上就是把隱性知識外顯化，這是知識管理的核心動作。
