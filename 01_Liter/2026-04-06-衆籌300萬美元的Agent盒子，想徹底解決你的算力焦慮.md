## 核心洞察

> 「算力民主化」的下一步不是更便宜的雲端，而是把AI搬回本地——Pocket Lab 的爆款衆籌揭示：隱私、低延遲與個人化訂製，是雲AI永遠無法填補的需求缺口。

## 重點摘要

**產品關鍵數據**：

| 指標 | 數值 |
|------|------|
| Kickstarter 籌資 | 280萬美元（預計突破400萬） |
| 售價 | 1,399 美元（早鳥） |
| 重量 | 約300克 |
| 支援模型規模 | 最高120B參數 |
| 出貨時間 | 2026年8月 |
| 技術加速倍數 | 比傳統方式快11倍（PowerInfer） |

**核心技術**：PowerInfer 異構計算
- 「熱」參數（20%）高速常駐記憶體
- 「冷」參數（80%）按需調用
- 結果：消費級硬件跑企業級模型

**市場背景**：OpenClaw 開源框架爆紅 → Mac mini 搶購潮 → Agent Box 賽道浮出水面

## 值得深思的問題

1. **本地AI的隱私溢價**：用戶願意多付多少錢換取「數據不離開設備」？這個需求在哪些人群中最強烈？
2. **1,399美元的定價邏輯**：相比月費制雲AI，ROI 如何計算？對怎樣的用戶群體最有說服力？
3. **硬件入口的品牌策略**：Agent Box 品類剛成形，誰更可能建立品牌認知——生態整合者（如Apple）還是垂直深耕者（如Tiiny AI）？
4. **算力焦慮是真需求還是FOMO？**：衆籌熱度有多少是情緒驅動？實際日常使用場景是否支撐這個定價？
