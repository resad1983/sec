## 核心洞察

> 2024–25年旅客量超疫情前但非航空收入仍低於2019年的數據，揭示了體驗商業的核心矛盾：「人流到位，但消費轉化失敗」——根因是體驗相關性不足，不是流量問題，對百貨業有直接啟示。

## 重點摘要

| 面向 | 重點 |
|------|------|
| 核心數據 | 旅客量已超2019年，但非航空收入仍低於2019年 |
| 問題本質 | 不是流量問題，是體驗相關性問題 |
| 典範案例 | 樟宜Jewel（2019）、JFK TWA酒店、班加羅爾T2花園航廈 |
| 新指標 | ROX（Return on Experience，體驗回報） |
| 轉型方向 | 混合用途：零售、酒店、文化、娛樂、健康、本地飲食 |
| 策略重點 | 免稅需成為生活方式主張的一部分，而非單純價格優勢 |

- 機場城市 = 讓旅客和當地居民都願意來的「目的地」
- 短期財務指標壓力（concession週期）阻礙了體驗型運營商進駐意願
- 奢侈品牌機場貴賓室：同時展示品牌、提供服務、銷售商品——三位一體

## 值得深思的問題

1. **勤美誠品類比**：百貨的非零售收入（活動、展覽、餐飲、停留體驗）是否也存在類似「流量到位但轉化不足」的問題？如何設計ROX指標？

2. **城市目的地邏輯**：機場能成為城市目的地，台中的百貨/商圈能否同樣跳脫「日常採購」定位，成為「週末目的地」？民生路老宅群落的場所感如何轉化為留人動能？

3. **免稅→體驗的遷移**：文章指出免稅的競爭優勢將消失，未來必須附加故事與體驗。這個邏輯對傳統百貨的「折扣促銷」策略有何啟示？
