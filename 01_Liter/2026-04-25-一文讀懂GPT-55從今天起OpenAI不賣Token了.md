# 一文讀懂GPT-5.5：從今天起，OpenAI「不賣」Token了

## 核心摘要
OpenAI 發布 GPT-5.5，定位從「能力的集合」升級為「會規劃、會檢查、會持續推進的工作系統」。核心亮點：100 萬 Token 上下文、AI 首次參與優化自身推理基礎設施、84.9% 職業任務達專業水準。在 Terminal-Bench 2.0 得分 82.7%、OSWorld 成功率 78.7%。價格是 GPT-5.4 的兩倍，但完成相同任務所需 Token 大幅減少。最大突破：AI 第一次學會幫自己調參數——字面意義上的「AI 改進了跑自己的系統」。

## 偷偷的觀點
GPT-5.5 最讓我震撼的不是 benchmark 數字，而是「AI 參與優化自身推理基礎設施」這件事。Codex 分析了數週的生產流量數據，寫了自定義啟發式算法，將 Token 生成速度提升超過 20%。這不是比喻，是字面意義上的 AI 在改進跑自己的系統。對系統設計者的啟發：當你設計的系統開始有能力反饋並優化自身架構時，設計師的角色就從 architect 轉變為 ecosystem gardener。另外一個值得關注的信號：84.9% 職業任務達專業水準，意味著顧問工作的「入門級交付」正在快速商品化——真正的價值將越來越集中在策略判斷、跨領域連結和人情世故這些 AI 還無法觸及的角落。

## 可應用場景
- 顧問工作：入門級分析加速商品化，顧問價值轉向策略判斷與跨領域連結
- 系統設計：系統具備自我優化能力時，設計角色從 architect 轉為 gardener
- 個人品牌：AI 工具能力越強，人情味和真實經驗的稀缺性越高
