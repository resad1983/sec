## 核心洞察

> El Pollo Loco的逆轉密碼是「利潤×行銷×會員」三角同步強化：菜單創新帶動品類結構化、品牌事件建立文化相關性、數位會員系統轉化為可量化的消費頻率與金額成長。

## 重點摘要

| 指標 | 數值 |
|------|------|
| Q1同店銷售成長 | +5.8% |
| 餐廳利潤率 | 19.2%（+320基點） |
| 數位銷售佔比 | 28% |
| 會員消費頻率成長 | +13%（12個月） |
| 會員消費金額成長 | +17% YoY |

- **菜單策略**：Tostada品類從配角做成8.3%銷售比例，說明「品類主題化」的威力
- **文化行銷**：NCAA + Coachella組合，讓品牌存在於消費者的「文化記憶」而非只是「飢餓記憶」
- **會員分層設計**：日常福利（Loco Friday Drops）+ 個人化推薦 + 獨家體驗（VIP票）三層
- **擴張紀律**：新店先達到系統平均值，再加速向新市場推進

## 值得深思的問題

1. 不二製餅如何學習「菜單主題化」策略？是否有可能打造一個達到20%+銷售比的「品類主角」？
2. El Pollo Loco的「文化行銷」（活動贊助+品牌時刻）對台灣食品品牌有什麼可移植的做法？有哪些在地的「文化節點」可以佔領？
3. 數位會員系統的「個人化推薦+獨家體驗」設計，不二製餅的電商平台現在能做到哪一層？下一步的優先投資是什麼？
