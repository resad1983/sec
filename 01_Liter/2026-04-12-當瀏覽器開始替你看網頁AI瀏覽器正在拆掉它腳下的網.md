## 核心洞察

> 當 AI 替人「看」網頁，傳統流量邏輯（停留→廣告→轉化）全面失效，內容方必須在 Agent 調用層重新定義價值。

## 重點摘要

| 面向 | 重點 |
|------|------|
| 破壞機制 | AI 只抽取核心數據，廣告位、視覺設計、推薦算法全被繞過 |
| 商業影響 | 「停留時間」兌現廣告價值的模型被摧毀 |
| 內容方三路 | 當語料礦 / 付費授權築牆 / 原生為 Agent 設計 API |
| 產品新指標 | DAU 讓位給「Agent 調用滲透率」 |
| 新優化方向 | AIO（AI Interface Optimization）取代 SEO |

## 值得深思的問題

1. 偷偷的顧問服務內容（文章、案例）如何設計才能在 Agent 調用時被正確推薦？
2. 地方創生的在地資訊平台，在 AI 瀏覽器時代如何避免成為「被榨乾的語料礦」？
3. 品牌方若主動為 Agent 設計 API，定價邏輯應如何設計（按調用次數？按轉化？）
