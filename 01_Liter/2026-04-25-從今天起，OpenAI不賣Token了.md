## 核心洞察

> GPT-5.5 標誌著 AI 從「能力集合」轉型為「工作系統」，OpenAI 正在從賣 Token 轉向賣工作結果——這是 AI 商業模式的根本轉移。

## 重點摘要

- **效率突破**：100萬上下文窗口，同等延遲下更高智能；AI第一次學會幫自己調參數（參與訓練自身推理基礎設施）
- **測試成績**：Terminal-Bench 2.0 得分82.7%（超Claude Opus 4.7 13個百分點）；84.9%任務達到行業專家水平
- **定價邏輯**：輸入 /M Token、輸出 /M Token（GPT-5.4的兩倍），但官方強調完成同樣任務所需 Token 大幅減少
- **互動新設計**：思考前先給思路概述，用戶可隨時插話調整方向——更像「協作系統」而非被動工具
- **核心轉移**：從「能力集合」→「會規劃、會檢查、會持續推進的工作系統」

## 值得深思的問題

1. 「賣結果而非賣 Token」的模式，對個人顧問品牌來說有什麼定價啟示？偷偷的服務收費邏輯是否也應從「小時費」轉向「成果費」？
2. AI 成為「工作系統」後，顧問的核心價值要如何重新定義——人類判斷力和在地知識是否會成為更稀缺的護城河？
3. GPT-5.5 Pro API 定價 / 每百萬 Token，如何評估不同任務的 Token 用量以控制成本？
