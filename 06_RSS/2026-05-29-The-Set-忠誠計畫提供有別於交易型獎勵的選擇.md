一家總部位於倫敦、代表獨立豪華酒店的品牌聯盟，正將自己定位為對抗高端酒店業日益同質化的力量，認為情感連結與獨特體驗比傳統的積點式忠誠計畫更為重要。

執行長 Robin Stangroom 在接受 TTG Asia 訪問時表示，The Set 的忠誠策略圍繞著個人連結而非交易型獎勵。該公司在 2021 年轉型為純品牌聯盟模式，此前在倫敦、巴黎和阿姆斯特丹經營三家自有物業。

Robin Stangroom 指出，豪華旅客既尋求服務品質的保證，也渴望更個人化、更真實的體驗。

The Set 的會員計畫「The Set Discovery」與 Global Hotel Alliance（GHA）合作，會員可享有超過 950 間酒店、橫跨 50 個品牌及 100 個國家的權益，會員人數超過 3,400 萬。無論是直接預訂、透過旅遊顧問或 GDS 管道，會員均可獲得 Discovery Dollars，但 OTA 預訂不包含在內。

「我們沒有疏遠旅遊顧問，這在我們的行業版圖中是非常重要的環節，」Stangroom 表示。

該公司透過非競爭性投資組合模型打造差異化，通常每個目的地僅限一家物業。Stangroom 表示，這讓獨立酒店在保有獨特性的同時，也能提供清晰的奢華定位。

「豪華旅客想要一個安全網，確保他們獲得頂級服務，」他說。「但他們同時也想要更個人化、更真實的體驗。而我們兩者都能提供。」

目前的會員包括香港的 The Upper House、曼谷的 The Siam，以及柬埔寨的 Shinta Mani Wild——這是一間由 Bill Bensley 設計、擁有 15 頂帳篷的物業，客人需透過叢林天際滑索抵達。

Stangroom 認為，豪華酒店業面臨的最大風險之一是他所謂的「米色化」（beigification）——隨著品牌變得越來越謹慎，酒店設計與體驗也越來越趨同。他補充說，對獨立酒店而言，獨特性不是創意賭注，而是商業策略。

「旅行的意義在於拓展視野、展現不同的觀點，」他說。「如果每樣東西看起來都一樣，這就不可能實現。」

對於銷售高端客戶的旅遊顧問而言，The Set 定位為一個既能提供一致品質、又不會犧牲獨特性的選擇。
